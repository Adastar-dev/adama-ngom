Projet de Fin d'Études · Note 16 / 20

Audience+

Application web pour dématérialiser les audiences d'état civil au Sénégal. Un juge préside la séance en visioconférence (Jitsi Meet), les parties comparaissent à distance, le greffier instruit le dossier, et OpenAI Whisper retranscrit l'audience au fil de la séance. Six rôles distincts avec espaces dédiés. L'authentification, les convocations et les notifications passent toutes par email (OTP inclus). Le backend Laravel expose une API REST complète ; le frontend React (Vite + Tailwind) est structuré par composants avec gestion d'état centralisée. Principale difficulté surmontée : découper le flux audio Jitsi en segments et les envoyer à l'API Whisper pour une transcription quasi temps réel.
