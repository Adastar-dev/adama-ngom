Projet de Fin d'Études · Note 16 / 20

Audience+

170 tests automatisés 6 rôles distincts Backend dockerisé PV scellés SHA-256

Application web pour dématérialiser les audiences d'état civil au Sénégal. Un juge préside la séance en visioconférence (Jitsi Meet), les parties comparaissent à distance, le greffier instruit le dossier, et l'enregistrement de l'audience est transcrit par Whisper (via l'API Groq) pour préparer le procès-verbal. Six rôles distincts avec espaces dédiés. L'authentification, les convocations et les notifications passent toutes par email (OTP inclus). Le backend Laravel expose une API REST complète ; le frontend React (Vite + Tailwind) est structuré par composants avec gestion d'état centralisée. Principale difficulté surmontée : sécuriser la salle d'audience Jitsi auto-hébergée, avec un accès par jeton JWT, une salle d'attente où chaque partie confirme son identité par code OTP, et aucune entrée avant le juge.
